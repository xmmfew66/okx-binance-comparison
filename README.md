## 手續費之外，還要比較哪些成本？

### 提幣費

提幣通常不是單純按照交易所名稱收固定費用，而是根據幣種、網路和當時的鏈上狀況計算。USDT 使用 Ethereum、Tron、Arbitrum 或其他網路，成本可能完全不同。

提幣時要同時確認：

- 接收平台支援的網路。
- 最低提幣數量。
- 手續費由誰支付。
- 是否需要額外的地址白名單或安全等待期。
- 網路擁堵時是否會調整費用。

把資產提到錯誤網路，通常不是「手續費多一點」這麼簡單，可能直接造成資產無法到帳。

### 點差與滑點

交易手續費低，不代表總成本一定低。如果交易對流動性不足，買入價和賣出價之間的點差可能比手續費更高。市價單在波動大的時候，也可能出現明顯滑點。

如果你交易的金額較大，可以考慮：

- 使用流動性較高的主流交易對。
- 分批下單。
- 使用限價單。
- 先查看訂單簿深度。
- 不要在劇烈波動時盲目追價。

### 法幣入金成本

信用卡、銀行轉帳、第三方支付和 P2P 的費用可能不同。某些支付方式看起來沒有明確手續費，但會透過匯率或價差收取成本。

所以比較 OKX 和幣安時，最好把完整路徑算一次：

> 入金費用 + 買入價差 + 交易手續費 + 提幣費 + 出金費用

只看交易費率，容易把最小的一項成本當成全部成本。
